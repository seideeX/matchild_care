🏥 Maternal & Child Care
Management System

Comprehensive Healthcare Solution for Mothers and Children

Powered by Laravel & React

📋 Introduction

A comprehensive web-based system designed to streamline maternal and child healthcare management.

What is it?

  • Digital health record management system
  • Connects patients and healthcare providers
  • Tracks prenatal care, delivery, and child immunization
  • Automated appointment reminders via SMS
  • Educational resources for pregnant mothers

✨ Key Features

👩‍⚕️ For Healthcare Workers

  • Patient registration & management
  • Prenatal visit tracking
  • Nutritional assessments
  • Delivery information records
  • Child immunization tracking
  • Automated SMS notifications

🤰 For Patients

  • Personal health dashboard
  • Complete medical records access
  • Educational videos & articles
  • Pregnancy tips & guidance
  • Appointment reminders
  • Profile management

⚙️ Technology Stack

Backend

  • PHP 8.2
  • MySQL Database
  • RESTful API
  • Semaphore SMS API

Frontend

  • React.js
  • Inertia.js (SPA)
  • Tailwind CSS
  • Lucide Icons
  • Responsive Design

Additional Features

  • Role-based access control (Spatie Permissions)

  • Secure authentication
