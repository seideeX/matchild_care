# 📱 SMS Quick Reference Card

**👉 Print this page and keep at your desk!**

---

## 🚀 Quick Start

### To Send SMS:
1. **Dashboard** → Click purple **"Send SMS"** button
2. **Choose template** from dropdown
3. **Select patient(s)**
4. **Fill in details** (date, time, etc.)
5. **Check preview** (green box)
6. **Click "Send SMS Now"**

---

## 📝 Important Rules

### ✅ DO:
- ✓ Preview before sending
- ✓ Keep messages under 160 characters
- ✓ Use templates for consistency
- ✓ Check SMS logs after sending
- ✓ Verify phone numbers are correct

### ❌ DON'T:
- ✗ Delete words in `{curly brackets}`
- ✗ Make very long messages
- ✗ Send without previewing
- ✗ Edit templates without training
- ✗ Forget to check delivery status

## 🆘 Quick Troubleshooting

| Problem | Solution |
|---------|----------|
| Patient not showing | Check phone number in their record |
| Message too long | Keep under 160 characters |
| Can't find template | Check if it's turned ON |
| Browser error | Ignore if SMS still sends |

## 💡 Quick Tips

1. **Search patients** - Type name in bulk mode
2. **Preview always** - Green box shows final message
3. **Check logs** - Verify SMS was sent
4. **Test first** - Send to yourself before bulk
5. **Under 160 chars** - Stays as 1 SMS

---

## 🔐 Template Safety

### Safe to Edit:
✅ Regular words
✅ Punctuation
✅ Template name
✅ Notes section

### DON'T Touch:
❌ `{patient_name}`
❌ `{appointment_date}`
❌ Any text in `{brackets}`

---

## 📊 Message Length

- **Under 160** = 1 SMS ✅
- **161-320** = 2 SMS ⚠️
- **Over 320** = 3+ SMS 🚫

**Keep it short!**

## 🎯 Success Checklist

## 📱 After Sending

1. ✅ Check for success message
2. ✅ Go to Logs page
3. ✅ Find your SMS
4. ✅ Verify status is "Sent"
5. ✅ (Optional) Call patient to confirm

## 🆘 Emergency Contacts

**If SMS not working:**
- Check Logs page first
- Verify phone number
- Ask IT support
- Check Laravel logs

**If browser error:**
- Ignore if SMS still sends
- Use incognito mode
- Disable extensions
